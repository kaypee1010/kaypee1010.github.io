🪶 Level 1 · Scribe: A sentence is data: the string

The case: You are a scribe in a manuscript room. A line of Tagore must be copied, counted, shouted and whispered without a single slip.

Hook

Read one line of Gitanjali aloud. Now count its letters on your fingers. Slow, right? A computer does it before you finish saying the first word, because to a computer the line is a string of beads, one character on each bead.

See it move

The formal word

Stringtext the computer stores as a sequence of characters, one after another, each with a position number

In plain words: Python keeps text inside quotes. That quoted text is called a string. You can measure it with len, shout it with .upper(), whisper it with .lower(), and swap a word with .replace().

Worked example: one line of Tagore

  1. Step 1. line = "Where the mind is without fear"
  2. Step 2. print(line)
  3. Step 3. print(len(line))
  4. Step 4. print(line.upper())
  5. Step 5. print(line.replace("fear", "doubt"))

CoreCopy and shout

Change the line to any line you like (keep the quotes). Run. Then make it shout.

StretchCount and whisper

Print how many characters your line has, then print it whispered (lower case).

ChallengeSwap a word

Replace one word with another so the line means something new. Predict the output before you run.

Common mix-up: Quotes must open and close: "Where the mind is" works, "Where the mind is does not.

Common mix-up: Case matters to a computer: "Fear" and "fear" are two different strings.

A sentence is data. Once it is a string, the computer can measure it, change it and copy it a million times without tiring.

print(line)

What does this print?

print(line.upper())

📚 Level 2 · Collector: A poem is a list of lines

The case: You are collecting a poem for an anthology. You need to know how many lines it has, which line is last, and which line is the longest.

Hook

Read Gitanjali 35 line by line and number the lines as you go. Line 1, line 2 ... A list is exactly that: a shelf of items in order, each with a number.

See it move

The formal word

Listan ordered collection of items, counted from 0

In plain words: Square brackets make a list. Each item sits at a position, and the positions start at 0, not 1. len counts the items, append adds one at the end, and .split() turns a line into a list of its words.

Worked example: the lines of a poem

  1. Step 1. poem = [
  2. Step 2. ]
  3. Step 3. print(len(poem))
  4. Step 4. print(poem[0])
  5. Step 5. print(poem[-1])

CoreCount the lines

Add one more line to the list (inside the brackets, in quotes, with a comma). Run and watch the count change.

StretchSplit a line into words

Split the second line into words and count them. Then try the first line.

ChallengeThe longest line

Python can pick the longest line for you. Predict which line wins before you run.

Common mix-up: Counting starts at 0: poem[1] is the second line. poem[-1] is a handy way to say the last one.

Common mix-up: Every item needs quotes and a comma after it, or Python glues two lines into one.

A list keeps things in order and lets you reach any one by its number. A poem, a reading list, a cast of characters: all lists.

🔍 Level 3 · Reader: Reading a text word by word: the loop

The case: A scholar wants every word longer than five letters in a sonnet, and every line that mentions summer. Reading once, carefully, word by word.

Hook

How does a careful reader find every 'summer' in a sonnet? Not by magic. By reading every word once and checking each. A loop is that: do the same small thing for every item.

See it move

The formal word

Loopdo this for every item, one at a time

In plain words: for word in words: means take each word in turn and run the indented lines below for it. The indented block is the work done per word; the name after for is yours to choose.

Worked example: walk through a line

  1. Step 1. line = "Rough winds do shake the darling buds of May"
  2. Step 2. for word in line.split():

CoreWalk through a line

Run it. Then change the line to one of your own and run again. Watch the loop visit every word.

StretchOnly the long words

Print only the words longer than 5 letters. Change 5 to 7. What survives?

ChallengeEvery line with 'summer'

Loop over the lines of Sonnet 18 and print each line that contains the word summer. This is a concordance in five lines.

Common mix-up: The lines inside the loop must be indented (4 spaces). Python uses the indent to know what belongs to the loop.

Common mix-up: The word after for is a name you choose: for w in words: works the same as for word in words:.

A loop reads for you. The thing you do per word is the only part you write.

🗂️ Level 4 · Archivist: A word-frequency index: the dictionary

The case: An archivist must say which words Jane Austen uses most in her opening page, and whether 'truth' or 'fortune' comes up more often, without reading it twice.

Hook

Picture an index-card box. Every time you read a word, you find its card and add a tally mark; a new word gets a new card. At the end, the box is a word-frequency index. Python calls that box a dictionary.

See it move

The formal word

Dictionarya lookup from a key to a value, like a word to its count

In plain words: A dictionary keeps pairs: a key (the word) and a value (its count). counts[word] looks up a card. counts.get(word, 0) looks it up and says 0 if there is no card yet. Sorting the pairs by value gives the top words.

Worked example: count the words of one line

  1. Step 1. line = "the eye of heaven shines and the gold of the sun"
  2. Step 2. counts = {}
  3. Step 3. for word in line.split():
  4. Step 4. print(counts)
  5. Step 5. print(counts["the"])

CoreFill the card box

Run it and read the dictionary. Then look up a different word in the last line.

StretchTop 5 words of Austen's opening

Count every word of the Pride and Prejudice opening (lower-cased, punctuation stripped) and print the top 5.

ChallengeDrop the stop words

Small words (the, of, a) always win. Remove them and see which words of meaning rise to the top.

Common mix-up: Looking up a card that does not exist (counts["zebra"]) stops with a KeyError. counts.get("zebra", 0) answers 0 instead.

Common mix-up: "The" and "the" get two cards unless you lower-case the text first.

A dictionary remembers. Word to count, name to age, title to author: whenever you want to look something up, you want a dictionary.

Test yourself

What does this print?

print(counts["love"])

This stops with an error. Why?

print(counts["time"])

After this loop, what is counts["so"]?

counts = {}
for word in "so long so long so".split():
counts[word] = counts.get(word, 0) + 1

🕵️ Level 5 · Literary Detective: The reader's choice: if, and a writer's fingerprint

The case: Four unsigned passages arrive at the archive. Your team must name the writer of each using only counts: words per line, how often thee, thou and thy appear, and whether Mr. or Mrs. turns up.

Hook

Every writer leaves fingerprints: Shakespeare's short lines and his thee and thou; Tagore's long, flowing lines, also with thou; Austen's Mr. and Mrs. and long sentences; Wordsworth's short lines without any thee. If you can count, you can detect.

See it move

The formal word

If-statementdo this only when a condition is true; otherwise do something else

In plain words: if asks a question about the data and runs a block only when the answer is yes; elif asks the next question; else catches the rest. A detective's rule is a chain of ifs.

Run it. Read the three numbers for each writer: words per line, thee/thou/thy count, Mr./Mrs. count.

TeamName the writer of a mystery passage

Fingerprint MYSTERY_A (then B, C, D). Apply the rule. Agree as a team, then submit your guess below with your confidence.

Common mix-up: A rule that works on four writers can fail on a fifth text: the opening of Sonnet 116 has no thee or thou, so the rule calls it Wordsworth. Counting finds patterns; a human reader decides what they mean.

Common mix-up: The order of the if, elif and else lines matters: the first question that says yes wins.

Counting is evidence, not proof. The computer finds the pattern; you make the argument.

🔁 Revise

  • Text is data: string, list, loop, dictionary, if.
  • Counting is evidence, not proof.

  1. String

    Text in quotes: a sequence of characters, numbered from 0. len() counts them.

  2. List

    An ordered shelf of items in square brackets, counted from 0. poem[-1] is the last item.

  3. Loop (for)

    Do the indented lines once for every item: for word in words:

  4. Dictionary

    A lookup from key to value, like word to count: counts[word] = counts.get(word, 0) + 1

  5. if / elif / else

    Run a block only when a condition is true; the first yes wins.

  6. .split()

    Turns a line into a list of its words (splits on spaces).

  7. .upper() / .lower()

    Shout or whisper a string (every letter capital or small).

  8. Concordance

    Every line where a word appears: a loop with an if inside.

  9. Author fingerprint

    Counts that tell writers apart: words per line, thee/thou rate, Mr./Mrs. rate. Evidence, not proof.
